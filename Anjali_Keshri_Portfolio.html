SkillPath Navigator

An AI-powered placement-preparation platform in development, designed to help college students prepare for target roles through personalized learning paths, practice and interview preparation.

  • Planned modules: resume analysis, personalized roadmaps, mock tests, AI assistance and interview preparation.
  • Selected architecture: Python FastAPI backend, PostgreSQL with SQLAlchemy ORM and JWT authentication.
  • Gemini integration is kept behind an abstraction so the AI provider can be changed as the project evolves.

SafeWalk

A pedestrian-safety navigation application that scores real streets using OpenStreetMap context such as lighting, activity and open shops, then compares safer and faster walking routes.

  • Explores safest-versus-fastest routing with time-of-day and route-priority controls.
  • README-documented features include nearby safe spots, crowd reports with verification and a safety timeline.
  • Includes safety workflows such as share-my-walk, SOS and Guardian safe-arrival alerts.
